# Виртуальный дипломат

Учебный MVP тренажёра международных переговоров на Next.js. Включает интерфейс на русском языке, стороны Беларусь/США, три стиля, чат, объяснимый прогресс, эмоции Алекса, обработчик переговоров и демо-ответы без API-ключа.

## Запуск локально

1. Установите Node.js 20.9 или новее.
2. Выполните `npm install`.
3. Скопируйте `.env.example` в `.env.local` и при наличии ключа задайте `XAI_API_KEY`.
4. Запустите `npm run dev`, затем откройте `http://localhost:3000`.

Без `XAI_API_KEY` приложение работает в демо-режиме. Оно возвращает простые контекстные учебные ответы и подходит для показа интерфейса, но не имитирует полноценную языковую модель.

## Подключение Grok / xAI

Переменные окружения:

| Переменная | Назначение | Значение по умолчанию |
|---|---|---|
| `XAI_API_KEY` | Секретный API-ключ; используется только сервером | нет — демо-режим |
| `XAI_BASE_URL` | Совместимый с OpenAI адрес API | `https://api.x.ai/v1` |
| `XAI_MODEL` | Имя доступной модели xAI | `grok-3-mini` |
| `SESSION_SECRET` | Длинный случайный секрет для подписи cookie | случайный секрет процесса |

Никогда не добавляйте API-ключ с префиксом `NEXT_PUBLIC_` и не коммитьте `.env.local`. Укажите `SESSION_SECRET` в deployment: иначе после перезапуска процесса сессии перестанут распознаваться. Если меняете модель, проверьте, что она поддерживает Chat Completions и Structured Outputs с JSON Schema. Сервер проверяет и ограничивает модельный ответ до того, как отправить его браузеру.

## Публикация на Vercel

Импортируйте репозиторий в Vercel, выберите Next.js и добавьте серверные переменные `XAI_API_KEY`, `XAI_MODEL`, при необходимости `XAI_BASE_URL`, а также собственный случайный `SESSION_SECRET`. Затем создайте deployment. При отсутствии API-ключа сайт остаётся доступным в демо-режиме.

Картинки маскота можно добавить в `public/images/` под именами `alex-neutral.png`, `alex-friendly.png`, `alex-thinking.png`, `alex-curious.png`, `alex-concerned.png` и `alex-happy.png`. До их добавления сайт показывает CSS-иллюстрацию Алекса.

## Временные сессии и приватность

Сервер выдаёт привязанную к IP и подписанную случайным идентификатором HttpOnly cookie. Диалог хранится в памяти Node.js до 10 минут бездействия; применяются ограничения частоты запросов, размера контекста и длины сообщения. IP используется только для временной привязки/лимита в процессе приложения. Сообщения передаются выбранному провайдеру xAI только при настроенном ключе. Интерфейс предупреждает пользователей не вводить личные данные.

**Ограничение демо:** память и лимиты находятся в одном процессе. Vercel может распределять запросы между несколькими независимыми экземплярами и удалять их после простоя, поэтому один пользователь может попасть на разные экземпляры; сессии и ограничения не синхронизируются и не гарантируются глобально. Для публичного или учебного использования замените `lib/session-store.ts` общим хранилищем с TTL и атомарными лимитами, например Redis/Upstash; для более устойчивой привязки используйте идентификатор сессии и политику приватности, не полагаясь исключительно на IP.

## Команды

- `npm run dev` — локальная разработка.
- `npm run build` — production-сборка для Vercel и Node.js-хостинга.
- `npm start` — запуск собранного приложения.
